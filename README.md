# vcf-target-variant-mapper
vcf-target-variant-mapper v2.0 is a reproducible VCF/summary-statistics pipeline integrating geneGPS/MAGMA multi-trait gene-level analysis, Bayesian colocalization (colocboost/HyPrColoc/POEMColoc), and functional prioritization. It explicitly handles truncated p&lt;1e-5 signals via auditable degradation paths and includes configurable workflows.
