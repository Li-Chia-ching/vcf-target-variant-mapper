# DELLA / GRAS 蛋白结构域架构

用于 Stage 4/6 的变异-结构域映射。坐标为**紫花苜蓿 DELLA 参考编号**（以 Msa085132 类蛋白为参照，约 537 aa），不同物种/同源拷贝请按实际蛋白长度线性调整或用 Pfam/InterPro 实测坐标覆盖。

## 结构示意（N → C）

```
 1        56   70  81  95        200   260   330   380   420  460  500 530 540 570  537
 |--N-var--|--DELLA--|--TVHYNP--|......|--LHRI--|..|--VHIID--|..|--LHRII--|--PFY--|--SAW--|
```

| 结构域/基序 | 位置（参考） | 说明 |
|---|---|---|
| N 端可变区 | 1–55 | 无保守基序，变异容忍度高 |
| **DELLA 基序** | 56–70 | 与 GID1 受体互作核心，错义变异常致矮化表型 |
| **TVHYNP 基序** | 81–95 | DELLA 亚家族签名基序 |
| LHRI | 200–260 | GRAS 家族 Leucine-rich 区 I |
| VHIID | 330–380 | GRAS 核心基序，DNA/蛋白互作 |
| LHRII | 420–460 | Leucine-rich 区 II |
| PFY | 500–530 | GRAS 家族 C 端保守基序 |
| SAW | 540–570 | GRAS 家族 C 端基序（部分蛋白延伸至 570 以后） |

## 判读常规

- **DELLA / TVHYNP 基序内的错义变异**：文献常规视为高优先级候选（GA 信号通路核心）。
- **VHIID / SAW 基序内变异**：可能影响转录调控活性，需结合保守性（Stage 7 熵值 < 0.2 严格保守位点权重更高）。
- **N 端可变区变异**：多为中性，除非落在磷酸化位点或已知 degron。
- **埋藏位点（ASA < 20 Å²）+ 严格保守（熵 < 0.2）的错义变异**：最可能破坏折叠/功能，优先做实验验证。
